# Data Science Graduate Program Assessment

This repository contains my work for the PwC Data Science Graduate Program Assessment.

The assessment brief asks for analysis files, code and/or notebooks, supporting visuals or mock-ups, a brief README explaining the approach, and a dashboard or visual view of the analysis/model outcomes. It also asks candidates to be clear about any AI use during the assessment.

## Project Status

Initial repository setup is complete.

Current contents:

- `Data science graduate program assessment brief (2).pdf` - assessment brief
- `environment_sanity_check.ipynb` - checks that Python, common data science libraries, Jupyter, and Streamlit are installed
- `.gitignore` - excludes generated files, local environments, caches, and large local data artifacts
